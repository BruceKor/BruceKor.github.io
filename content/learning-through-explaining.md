阅读时的熟悉感，和离开材料之后的理解，是两种值得分别检验的状态。一份学习笔记，可以围绕「我能否重新解释这个概念」展开。

## 用自己的语言重写

合上材料，用几句话描述刚刚学到的内容。先不追求完整，试着说清楚：它是什么、用来做什么、在什么条件下成立。

写不下去的地方，就是下一轮阅读的入口。

## 找一个足够小的例子

选择一个能手工推演的例子。先写下预期，再逐步执行，最后比较结果。

```python
# 学习笔记可以同时保留输入、预期与观察。
experiment = {
    "question": "这个方法在一个小例子里怎样工作？",
    "expected": None,
    "observed": None,
    "next_question": "",
}
```

例子的价值，在于把抽象的描述拆成可以观察的步骤。

## 记录理解的变化

一份可回顾的笔记，可以保留三个位置：

- **最初的理解**：第一次阅读时，我如何解释它？
- **改变的部分**：哪个例子、推导或讨论改变了理解？
- **还不确定的地方**：下一次需要继续确认什么？

## 为下一次学习留下入口

结尾不必重复全文。写下一个具体的问题，或一个可以完成的小实验，让学习在下一次打开笔记时自然继续。
